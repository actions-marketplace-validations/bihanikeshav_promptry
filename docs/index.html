~/capabilities

Keep a prompt honest.

From the first commit to the cost of every call in production.

#Zero-config capture

-Bolt a telemetry wrapper around every call site before you see a single number.
+Swap from openai import OpenAI for from promptry.openai import OpenAI — cost, tokens, and latency, streaming and failures included. Same idea in JS via wrapOpenAI().

#Prompt versioning

-Tweak the prompt, ship it, forget which version is live.
+Every track() call is content-hashed. Diff any two versions.

#Eval suites

-Ad-hoc asserts scattered across notebooks and PR comments.
+Eight assertion types: semantic, schema, judge, tool-use, all in one @suite.

#Regression & drift detection

-Prompt works. Six weeks later, scores have crawled down and nobody knows what broke it.
+Bisect to the run that broke it; a rolling Mann-Whitney U test flags slow drift before you do.

#Live prompt CMS

-Fixing a typo in a prompt means a code change and a redeploy.
+render_prompt() serves dashboard-edited templates live — no redeploy.

#Cache optimization

-Inputs sit at the top of the prompt, quietly busting the prefix cache on every call.
+Reorder inputs to the end, consolidate near-duplicate prompts, flag redundant wording — measured, never auto-applied.

#Cost tracking

-Bill spikes. Which prompt? Which model? Nobody knows.
+Module → prompt → call drill-down, plus daily/monthly budget caps that alert to Slack, PagerDuty, or a webhook on breach.

#Call traces + feedback

-A multi-step agent burns tokens and you can't tell which step; a thumbs-down vanishes into a log file.
+Wrap a run in trace() for a per-step cost waterfall. Opt-in, sampled request/response capture. Ratings ingest from your app via API.

#CI + GitHub Action

-Reviewer eyeballs a prompt diff and hopes for the best.
+One-line GitHub Action fails the build and posts the score delta.

~/start

Local SQLite. No Docker. No SaaS. No account.

Install, wrap one prompt, write one assertion. Promptry takes it from there. Deterministic assertions by default — LLM-as-judge is opt-in, for when you actually want to spend the tokens.
